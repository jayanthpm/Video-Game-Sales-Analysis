# 🎮Video-Game-Sales-Analysis
This project analyzes global video game sales data to uncover trends in game performance across regions, genres, platforms, and publishers. The dashboard provides interactive insights into market dominance, regional contribution, and historical sales trends, built entirely using Power BI.

🎯 Objectives
-
- Analyze global and regional video game sales
- Identify top-performing games, genres, platforms, and publishers
- Understand sales trends over time
- Present insights through an interactive Power BI dashboard

🛠 Tools & Technologies
-
- Power BI Desktop
- Power Query (Data cleaning & transformation)
- DAX (Measures & calculations)
- Excel / CSV (Source data)

🔧 Data Cleaning & Preparation
-
- Verified correct data types for all columns
- Handled missing values in Year and Publisher columns
- Renamed columns for better readability
- Kept full dataset intact and used filters & slicers instead of deleting data


📌 Dashboard Features
-
- KPI Cards for high-level metrics
- Top 10 Games by Global Sales
- Sales Trend Over Time
- Regional Sales Contribution
- Publisher Performance (Grouped Analysis)
- Interactive slicers (Year, Platform, Genre, Publisher)
- Clean dark-themed UI optimized for readability

🧠 Key Insights
-
- North America contributes the highest share of global sales
- Action and Sports genres dominate global performance
- A small number of publishers account for a large portion of total sales
- Video game sales show clear growth and decline patterns across years
